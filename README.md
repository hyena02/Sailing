# ⚓ SAILING

### 해운·선박 전문 구인구직 플랫폼

해운·선박 분야의 채용정보와 해운 관련 업체정보를 제공하고,
구직자와 기업 및 해운업체를 연결하는 웹 서비스입니다.

해운업 특성에 맞춰 직무, 선박, 항로, 근무형태 등의 정보를
구조화하여 제공하고 간편지원, 해운정보, 실시간 문의 채팅,
면접·CBT·AI 기능 등을 구현하는 것을 목표로 합니다.
